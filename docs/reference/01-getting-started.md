# 01. 시작하기

> 기준 소스 버전: `ccad021`
> 관련 문서: [명령어 레퍼런스](02-command-reference.md) · [작성 보조 도구](03-authoring-tools.md)

이 문서는 UnivRPA로 첫 자동화 스크립트를 작성·실행하는 과정을 처음부터 끝까지 안내합니다.

---

## 1. 스크립트 시트 구조

UnivRPA 스크립트는 **하나의 행이 하나의 명령**인 6열 테이블입니다.

| 열 | 헤더 | 용도 | 예시 |
|----|------|------|------|
| A | `ROW` | 자동 줄번호 (포맷 시 생성) | `1`, `2`, `3` … |
| B | `COMMAND` | 실행할 명령어 | `CLICK`, `IF`, `TYPE` |
| C | `PARAM1` | 첫 번째 파라미터 | `100` (x좌표) |
| D | `PARAM2` | 두 번째 파라미터 | `200` (y좌표) |
| E | `PARAM3` | 세 번째 파라미터 | `500` (대기ms), 텍스트 |
| F | `COMMENT` | 자유 메모 (실행 시 무시) | `# 제출 버튼` |

> ⚠️ **파라미터 위치 주의**: 명령어마다 파라미터가 들어가는 열이 다릅니다. 예를 들어 `TYPE`·`SLEEP`·`GOTO`·`CALL`·`LABEL`의 주요 인자는 **PARAM3(E열)**에 들어가고, `NOTIFY`는 **PARAM1(C열)=표시초 / PARAM3(E열)=메시지**를 사용합니다. 명령어별 정확한 열 배치는 [명령어 레퍼런스](02-command-reference.md)를 반드시 확인하세요.

### 시트 판별 시그니처

작성 보조 기능(힌트·검증·포맷)은 **A1 = `ROW`**, **B1 = `COMMAND`** 를 동시에 만족하는 시트에서만 동작합니다.
일반 데이터 시트·로그 시트·설정 시트에서는 동작하지 않습니다.

---

## 2. 시트 준비 (포맷)

빈 시트에 명령어를 입력한 뒤, **`Ctrl`+`Shift`+`F`** (스크립트 포맷)를 누르면 포맷터가:

- 헤더 행(`ROW | COMMAND | PARAM1 | PARAM2 | PARAM3 | COMMENT`)을 멱등 생성하고
- A열 줄번호를 다시 매기고
- 블록 깊이에 따라 `>` 마커로 들여쓰기를 정리하고
- 카테고리별 색상·격자 서식을 일괄 적용합니다.

포맷터는 작성 중 언제든 다시 눌러도 안전합니다(같은 결과로 수렴). 자세한 동작은 [작성 보조 도구](03-authoring-tools.md)를 참고하세요.

---

## 3. 명령어 입력 흐름

1. **B열(COMMAND)** 셀에 명령어를 직접 타이핑합니다. 자동완성은 없습니다 — 명령어셋은 약 30여 개로 암기 가능한 규모입니다.
2. 명령어 셀을 선택하면 **상태표시줄(StatusBar)**에 파라미터 힌트가 표시됩니다.
   예) `CLICK | P1: x (num, required) | P2: y (num, required) | P3: 사후대기ms (num)`
3. `Tab` 키로 PARAM1 → PARAM2 → PARAM3 으로 이동하며 값을 입력합니다.
4. 값은 따옴표 없이 그대로 입력합니다.

### 주석

`#` 로 시작하는 COMMAND 셀은 실행 시 건너뜁니다.

```
# 이 줄은 실행되지 않습니다
```

선택한 줄을 일괄 주석/해제하려면 **`Ctrl`+`Shift`+`/`** 를 사용합니다.

---

## 4. 좌표·색상 캡처 (HUD)

클릭/대기 명령에 필요한 화면 좌표와 색상은 캡처 HUD로 손쉽게 얻습니다.

1. **`Ctrl`+`Shift`+`E`** 를 눌러 캡처 HUD(폼 캡션 **"매크로 헬퍼"**)를 엽니다.
2. 마우스를 대상 위치로 옮기면 HUD가 실시간으로 표시합니다:
   ```
   탐색 중...
   X: 1234
   Y: 567
   CLR: FF5733
   ```
3. **`CapsLock`** 키를 토글하여 캡처합니다. 두 가지 모드가 있습니다:

   - **클립보드 복사 모드 (기본)**: HUD가 `▶ 클립보드 복사됨 ◀`(붉은 배경)을 표시하고, `X[Tab]Y[Tab]색상` 형식이 클립보드에 복사됩니다. PARAM 셀에 붙여넣으세요.
   - **자동 입력 모드**: HUD의 `자동 입력 모드 (Auto-Fill)` 체크박스를 켜면, 캡처 시 `▶ 시트 입력 완료! ◀`(초록 배경)와 함께 **활성 셀에 X, 옆 칸에 Y, 그 옆 칸에 색상**이 자동으로 채워지고 커서가 다음 행으로 이동합니다.

4. HUD 창을 닫으면 캡처 모드가 종료됩니다.

---

## 5. 실행

스크립트 시트를 활성화한 상태에서 **`Ctrl`+`Shift`+`W`** (RPA 실행)를 누릅니다.

실행 엔진은:

1. 활성 시트의 `A1.CurrentRegion`(A1부터 이어진 데이터 블록)을 읽습니다.
2. 데이터가 없거나 헤더만 있으면(행 2개 미만) **"실행할 데이터가 없습니다. (현재 시트: …)"** 를 알리고 멈춥니다.
3. 모든 `LABEL`을 먼저 스캔해 점프 대상을 등록합니다.
4. 첫 데이터 줄부터 줄 단위로 실행합니다.

### 실행 상태 폼

실행이 시작되면 좌상단에 슬림한 상태 창(캡션 **"RPA Running"**)이 떠서 진행 상황을 보여줍니다.

```
┌ RPA Running ───────────┐
│ Line 5/42              │   ← 현재 줄 / 전체 줄
│ CLICK 120 200 500      │   ← 실행 중인 명령 + 파라미터
└────────────────────────┘
```

### 실행 제어

| 키 | 동작 |
|----|------|
| `Pause` | 일시정지 / 재개 |
| `Esc` | 즉시 중단 (`매크로가 중단되었습니다.`) |

정상 종료 시 `매크로가 종료되었습니다.`, 오류 발생 시 `[에러] 라인 N / <명령> <설명>` 알림이 표시됩니다.

---

## 6. 첫 스크립트 따라하기

**시나리오**: 버튼을 클릭 → 화면이 흰색으로 바뀔 때까지 대기 → 이름 입력 → 확인 클릭 → 완료 알림.

| ROW | COMMAND | PARAM1 | PARAM2 | PARAM3 | COMMENT |
|-----|---------|--------|--------|--------|---------|
| 1 | CLICK | 542 | 375 | 500 | # 버튼 클릭 후 0.5초 대기 |
| 2 | WAIT_APPEAR | 100 | 100 | #FFFFFF | # 대화상자(흰색)가 뜰 때까지 대기 |
| 3 | TYPE | 50 |  | 홍길동 | # 50ms 간격으로 이름 입력 |
| 4 | CLICK | 680 | 400 | 500 | # 확인 클릭 |
| 5 | SLEEP |  |  | 2000 | # 2초 대기 |
| 6 | NOTIFY | 3 |  | 완료! | # 3초간 완료 알림 |

> `TYPE`의 텍스트와 `SLEEP`의 값은 **PARAM3(E열)**에, `NOTIFY`는 **PARAM1(C열)=표시초 / PARAM3(E열)=메시지**에 입력하는 점에 주목하세요.

**실행 절차**:

1. 위 표를 시트에 입력합니다 (좌표는 캡처 HUD로 채웁니다).
2. `Ctrl`+`Shift`+`F` 로 포맷을 정리합니다.
3. `Ctrl`+`Shift`+`W` 로 실행합니다.
4. 진행 상태 창을 확인하고, 필요하면 `Pause`로 멈추거나 `Esc`로 중단합니다.
