# 03. 작성 보조 도구

> 기준 소스 버전: `8438ce0`
> 관련 문서: [시작하기](01-getting-started.md) · [명령어 레퍼런스](02-command-reference.md)

UnivRPA는 Excel 시트를 코드 에디터처럼 쓰도록 돕는 작성 보조 기능을 제공합니다. 이 문서는 단축키, 포맷터, 실시간 검증·힌트, 라벨 이동, 주석 토글, 색상 캡처 HUD를 다룹니다.

---

## 1. 고정 단축키

워크북이 활성화되면 아래 4개 단축키가 등록됩니다 (`modScriptAssist.bas`의 `OnKey` 등록).

| 단축키 | 기능 | 매크로 |
|--------|------|--------|
| `Ctrl`+`Shift`+`/` | 선택 줄 주석 토글 | `ToggleSelectedCommandComment` |
| `Ctrl`+`Shift`+`F` | 스크립트 포맷 | `FormatRPAScript` |
| `Ctrl`+`Shift`+`W` | RPA 실행 | `RunRPA` |
| `Ctrl`+`Shift`+`E` | 색상·좌표 캡처 HUD | `StartHUD` |

---

## 2. 스크립트 포맷터 (`Ctrl`+`Shift`+`F`)

포맷터(`FormatRPAScript`)는 시각 렌더링의 단일 소유자로, 누를 때마다 시트 전체를 일괄 정리합니다.

- **자동 줄번호**: A열을 다시 매깁니다.
- **헤더 멱등 생성**: 빈 시트면 `ROW | COMMAND | PARAM1 | PARAM2 | PARAM3 | COMMENT` 헤더를 만듭니다.
- **깊이 기반 들여쓰기**: 블록 중첩 깊이에 따라 `>` 마커로 들여씁니다.
- **카테고리별 색상 강조**: 흐름/동작/비전/시스템 명령을 색으로 구분합니다.
- **블록·서브루틴 구조 시각화**: 중첩 블록의 들여쓰기 가이드와 `LABEL`/`RETURN` 경계를 표시합니다.
- **잘못된 흐름 표시**: 존재하지 않는 `LABEL` 대상, 고아 `RETURN` 등 구조 오류를 적색으로 강조합니다.

> 포맷터는 멱등(같은 입력 → 같은 결과)이라 작성 중 언제든 반복 실행해도 안전합니다.

---

## 3. 실시간 작성 보조 (Script Assist)

스크립트 시트(A1=`ROW`, B1=`COMMAND`)에서만 동작하며, **셀 서식은 절대 건드리지 않고**(포맷터 전담) 비시각 피드백만 제공합니다.

### 파라미터 힌트

`COMMAND`~`PARAM3` 영역의 셀을 선택하면 **상태표시줄(StatusBar)**에 해당 행 명령의 파라미터 스키마가 표시됩니다.

```
CLICK
P1: x (num, required)
P2: y (num, required)
P3: 사후대기ms (num)
```

`FOREACH_ROW`의 PARAM1 셀에서는 열린 워크북 후보가 상태표시줄에 표시됩니다. P1을 일부 입력하면 일치하는 워크북 이름 목록을 좁혀 볼 수 있습니다.

`COMMAND`~`PARAM3` 영역을 벗어나거나 비스크립트 시트로 가면 힌트는 즉시 해제됩니다.

### 검증과 오타 후보

`COMMAND`를 수정하면 즉시 검증합니다.

- **빈 셀 / 주석(`#`)**: 오류로 처리하지 않습니다.
- **미등록 명령어 / 허용되지 않은 IF·WHILE 연산자**: 셀에 오류 노트를 부착합니다.
- **미정의 변수**: `SET`/`INC`/`DEC`의 메모리 좌변은 정의로, RESOLVE 슬롯의 `{name}`은 사용으로 분석합니다. 사용 전에 정의되지 않은 변수는 오류 노트로 표시합니다.
- **미사용 변수**: 정의됐지만 사용되지 않은 변수는 경고로 표시합니다. 실행을 막는 하드 오류는 아닙니다.
- **오타 후보**: Levenshtein 거리 기반으로 가장 가까운 등록 명령어를 제안합니다 (`Did you mean CLICK?`). 후보가 유일할 때만 제안하며, 동률이면 제안하지 않습니다.
- **변수명 후보**: 미정의 변수와 가까운 정의된 변수명이 하나뿐이면 함께 제안합니다 (`Did you mean {score}?`).

변수 분석에서 `$` 접두 토큰, `$ROW.*`, `$PIXEL:*`, `$BLANK`, `$CLIP`, `$LOOP`, `$RIDX`는 사용자 변수로 보지 않습니다.

오류 노트는 셀의 레거시 메모(Comment)로 표시되며 본문이 `[ScriptAssist]` 태그로 시작합니다.

```
[ScriptAssist]
Unknown command: CLCIK
Did you mean CLICK?
```

> **사용자 메모 보존**: 셀에 사용자가 직접 단 메모가 이미 있으면 Assist는 노트를 덮어쓰지 않고, 오류를 StatusBar로만 알립니다. 오류가 해소되면 Assist가 만든 노트만 제거하고 사용자 메모는 유지합니다.

> **자동 수정 없음**: Assist는 셀 값을 바꾸지 않습니다. `CLCIK → CLICK` 같은 교정은 사용자가 직접 합니다.

## 4. 라벨 이동

스크립트 시트에서 `CALL`, `GOTO`, `LABEL`의 PARAM3(E열) 셀을 더블클릭하면 관련 위치로 이동합니다.

| 대상 | 동작 |
|------|------|
| `CALL` / `GOTO`의 PARAM3 | 해당 라벨 또는 줄번호 위치로 스크롤합니다. |
| `LABEL`의 PARAM3 | 최근에 이동해 온 `CALL` 원본 줄로 돌아갑니다. 최근 기록이 없으면 같은 라벨을 호출하는 첫 `CALL`을 찾습니다. |

대상을 찾지 못하면 상태표시줄에 `target LABEL not found` 또는 `source CALL not found` 안내가 표시됩니다.

---

## 5. 주석 토글 (`Ctrl`+`Shift`+`/`)

선택한 `COMMAND` 셀들을 일괄 주석/해제합니다 (`ToggleSelectedCommandComment`).

- 주석 접두는 `# ` (해시 + 공백)입니다.
- 선택 범위의 비어 있지 않은 명령이 **모두 주석 상태이면 해제**하고, 아니면 **일괄 주석** 처리합니다.
- 처리된 줄 수가 상태표시줄에 표시됩니다(`주석 처리` / `주석 해제`).

주석 줄은 실행 시 건너뜁니다.

---

## 6. 색상·좌표 캡처 HUD (`Ctrl`+`Shift`+`E`)

`StartHUD`는 화면 픽셀의 좌표와 색상을 셀에 옮기는 도구입니다 (폼 캡션 **"매크로 헬퍼"**).

1. 마우스를 대상 위치로 옮기면 HUD가 실시간으로 `X / Y / CLR(#RRGGBB)`을 표시합니다.
2. **`CapsLock`** 토글로 캡처합니다.

| 모드 | 동작 | 피드백 |
|------|------|--------|
| 클립보드 복사 (기본) | `X[Tab]Y[Tab]색상`을 클립보드에 복사 → 셀에 붙여넣기 | `▶ 클립보드 복사됨 ◀` (붉은 배경) |
| 자동 입력 (`자동 입력 모드 (Auto-Fill)` 체크) | 활성 셀에 X, 옆 칸에 Y, 그 옆 칸에 색상을 채우고 커서를 다음 행으로 이동 | `▶ 시트 입력 완료! ◀` (초록 배경) |

HUD 창을 닫으면 캡처 모드가 종료됩니다. (시작하기 문서의 [좌표·색상 캡처](01-getting-started.md#4-좌표색상-캡처-hud)와 동일)
