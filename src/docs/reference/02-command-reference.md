# 02. 명령어 레퍼런스

> UnivRPA 1.0.0 사용 매뉴얼
> 단일 출처(SSOT): 파라미터 정의는 `modCmdRegistry.bas`, 조건 연산자는 `modCondition.bas`(`IsConditionOperator`), 키 이름은 `modActions.bas`(`ParseKeyCode`) 등록값을 그대로 따릅니다.
> 관련 문서: [시작하기](01-getting-started.md) · [작성 보조 도구](03-authoring-tools.md)

총 **5개 카테고리, 36개 명령어**. 각 표의 `P1/P2/P3`은 시트의 `PARAM1(C) / PARAM2(D) / PARAM3(E)` 열에 대응합니다.

---

## 표기 규칙

- **필수**: 반드시 입력해야 하는 파라미터. (옵션)은 생략 가능.
- **타입**: `num`(숫자) / `str`(문자).
- **RAW / RESOLVE**: 파라미터의 토큰 처리 방식.
  - **RESOLVE** (기본): `{변수}`·`{$토큰}`을 실제 값으로 치환한 뒤 사용.
  - **RAW**: 치환하지 않고 원문 그대로 사용. `SET/INC/DEC`의 좌변(P1), `IF/ELSE_IF/WHILE`의 연산자(P2), `LABEL`의 라벨명(P3)이 RAW입니다.
- 실행 전에 모든 명령 행에서 명령어 이름, 필수 칸, 미사용 칸, 조건 연산자를 검사합니다. 예를 들어 `EXIT` 뒤에 `SLEP`이라는 오타가 있어도 첫 명령 실행 전에 해당 행을 알려줍니다. 변수와 픽셀 토큰은 실행 경로에서 값이 필요할 때 해석합니다.
- 명령이 사용하지 않는 칸은 비워 둡니다. 예를 들어 `KEY`의 사후 대기시간은 P3에 입력하고 P2는 비웁니다.

## A. 흐름 제어 (FLOW) — 19개

분기, 반복, 라벨/점프, 서브루틴을 담당합니다. 블록 명령은 시작–종료가 짝을 이루며 자유롭게 중첩됩니다.

| 명령어 | P1 (C) | P2 (D) | P3 (E) | 설명 |
|--------|--------|--------|--------|------|
| `IF` | 좌변 (str, 필수) | 연산자 (str, **RAW**, 필수) | 우변 (str, 필수) | 조건이 참이면 다음 줄 실행, 거짓이면 다음 `ELSE_IF`/`ELSE`/`END_IF`로 점프 |
| `ELSE_IF` | 좌변 (str, 필수) | 연산자 (str, **RAW**, 필수) | 우변 (str, 필수) | 앞 분기가 거짓일 때 평가되는 추가 조건 분기 |
| `ELSE` | — | — | — | `IF`의 거짓 분기 (선택) |
| `END_IF` | — | — | — | `IF` 블록 종료 |
| `WHILE` | 좌변 (str, 필수) | 연산자 (str, **RAW**, 필수) | 우변 (str, 필수) | 조건이 참인 동안 블록 반복 |
| `END_WHILE` | — | — | — | `WHILE` 블록 종료 (헤더로 복귀) |
| `REPEAT` | 반복횟수 (num, 옵션) | — | — | N회 반복. **0 또는 빈값이면 무한 반복**. 음수와 정수 반올림 결과가 0인 양수는 오류 |
| `END_REPEAT` | — | — | — | `REPEAT` 블록 종료 |
| `FOREACH_ROW` | 워크북 이름/경로 (str, 필수) | 시트 또는 `시트!주소` (str, 필수) | 순회모드 (str, 옵션) | 워크시트/범위의 데이터 행을 한 줄씩 순회 |
| `END_FOREACH` | — | — | — | 다음 데이터 행으로 이동하거나 순회 종료 |
| `SELECT` | 대상값 (str, 필수) | — | — | 다중 분기. 일치하는 `CASE`로 이동 |
| `CASE` | 비교값 (str, 옵션) | — | — | `SELECT` 안의 분기 라벨. 빈값/`ELSE`는 기본값 |
| `END_SELECT` | — | — | — | `SELECT` 블록 종료 |
| `BREAK` | — | — | — | 최내곽 루프(`WHILE`/`REPEAT`) 탈출 |
| `CONTINUE` | — | — | — | 최내곽 루프의 다음 반복으로 |
| `GOTO` | — | — | 정적 라벨명 (str, 필수) | 지정 라벨(대소문자 무시)로 무조건 점프 |
| `CALL` | — | — | 정적 라벨명 (str, 필수) | 서브루틴 호출. 복귀 주소를 스택에 저장 |
| `RETURN` | — | — | — | `CALL` 호출부로 복귀 (스택이 비면 오류) |
| `LABEL` | — | — | 라벨명 (str, 필수) | 점프 대상 라벨 정의. 실행 전 사전 스캔됨 |

> `GOTO`·`CALL`·`LABEL`의 인자는 **P3(E열)**에 들어갑니다 (P1·P2는 비움).

`GOTO`와 `CALL`은 정적 LABEL 이름만 허용합니다. 줄번호나 토큰을 대상으로 지정하면 실행 전에 거부됩니다.

`GOTO`로 IF 분기 바깥에서 그 분기 안으로 들어가거나, IF/ELSE_IF/ELSE의 다른 분기로 이동할 수 없습니다. 같은 분기 안의 이동과 분기 밖으로 나가는 이동은 허용합니다.

스크립트의 COMMAND와 PARAM1~3 셀에 Excel 오류값(`#DIV/0!`, `#N/A` 등)이 있으면 셀 주소를 표시하고 첫 명령 실행 전에 중단합니다. 오류값을 빈칸이나 기본값으로 바꾸지 않습니다.

스크립트 파라미터의 통화 서식은 원래 숫자의 정밀도를 줄이지 않습니다. 날짜 셀은 기존처럼 날짜 문자열로 해석합니다.

**블록 짝**: `IF ↔ END_IF`, `WHILE ↔ END_WHILE`, `REPEAT ↔ END_REPEAT`, `FOREACH_ROW ↔ END_FOREACH`, `SELECT ↔ END_SELECT`. 모든 블록이 짝을 이뤄야 하며, 가장 안쪽 블록부터 닫아야 합니다. `CASE`는 해당 `SELECT`의 직접 분기로, `ELSE`/`ELSE_IF`는 해당 `IF`의 직접 분기로 배치합니다. 다른 IF나 루프 안에 분기 라벨을 끼워 넣으면 실행 전에 거부됩니다.

서브루틴 영역은 CALL 대상 LABEL과 같은 블록 깊이, 같은 분기에서 처음 만나는 RETURN까지입니다. IF나 SELECT 분기 안에 LABEL을 두면 다음 ELSE_IF, ELSE 또는 CASE 전에 해당 분기의 RETURN이 있어야 합니다. IF 안의 조기 RETURN은 영역 끝으로 취급하지 않으며, GOTO로 서브루틴 영역을 넘나들 수 없습니다.

서브루틴 내부의 일반 점프용 LABEL은 영역을 나누지 않습니다. 같은 깊이의 다른 CALL 대상 LABEL을 만나기 전에는 RETURN이 있어야 합니다.

`BREAK`와 `CONTINUE`는 현재 CALL 안에서 시작한 루프에만 적용됩니다. 서브루틴 자체에 활성 루프가 없으면 오류로 중단하며, 호출자의 루프를 직접 탈출하거나 다음 회차로 넘기지 않습니다. 재귀 CALL의 IF와 루프 상태도 호출별로 구분합니다.

**루프 토큰**: 루프 안에서 `{$LOOP}`은 현재 반복 횟수(1부터)를 반환합니다.

### FOREACH_ROW

`FOREACH_ROW`는 열린 워크북 또는 읽기 전용 외부 워크북의 워크시트/범위를 메모리 스냅샷으로 읽은 뒤, 첫 행을 헤더로 보고 두 번째 행부터 반복합니다.

| 항목 | 설명 |
|------|------|
| P1 | 워크북 이름 일부 또는 파일 경로. `\`, `/`, `:`가 있으면 경로로 보고 읽기 전용으로 엽니다. 전체 경로가 같은 워크북만 재사용하며, 다른 경로의 같은 파일명이 열려 있으면 오류로 중단합니다. 새 파일을 여는 동안 VBA 매크로와 이벤트는 차단됩니다. |
| P2 | `Sheet1`, `Sheet1!A1`, `Sheet1!A1:C10` 형식. 시트명은 `'상세 매출'!A1:D20`처럼 작은따옴표로 감쌀 수 있습니다. |
| P3 | 빈값/`ALL_ROWS`는 모든 데이터 행, `VISIBLE_ROWS`는 필터나 숨김으로 보이는 행만 순회합니다. |

- 시트 전체 주소를 포함해 명시 범위가 크면 사용 범위와 겹치는 부분만 읽습니다. 표를 읽는 동안 Esc가 감지되면 부분 스냅샷을 폐기하고 본문 실행 전에 중단합니다.
- 비연속 범위(`Sheet1!A1:B3,A6:B7` 등)는 거부합니다. 하나의 연속된 표 범위를 지정하세요.
- 셀 값은 화면에 보이는 `.Text` 기준으로 읽습니다. 열 폭이 좁아 `####`로 보이는 값은 원 값과 표시 형식으로 복원해 읽습니다.
- 좁은 통화 열은 원래 숫자의 정밀도로 표시값을 복원합니다. 통화 서식의 숫자 헤더도 원값으로 읽어 `1.234561`과 `1.234562`를 서로 다른 열 이름으로 구분합니다.
- 데이터의 양끝 공백을 보존합니다. 헤더 이름의 양끝 공백만 제거합니다.
- 데이터 행이 없으면 블록 본문을 실행하지 않고 `END_FOREACH` 다음으로 이동합니다.

반복 안에서 사용할 수 있는 토큰:

| 토큰 | 값 |
|------|-----|
| `{$ROW.헤더명}` | 현재 행에서 해당 헤더 열의 값 |
| `{$RIDX}` | 현재 `FOREACH_ROW` 순번(1부터) |
| `{$RTOTAL}` | 현재 `FOREACH_ROW` 전체 순회 행수 |

`{$LOOP}`은 기존처럼 가장 안쪽 활성 루프의 반복 횟수입니다. `FOREACH_ROW` 안에 `WHILE`이나 `REPEAT`가 중첩되어 있으면, 행 순번은 `{$RIDX}`, 전체 행수는 `{$RTOTAL}`을 사용하세요.

### 예제

```
# IF / ELSE_IF / ELSE
IF | {결과} | EQ | 성공
  CLICK | 100 | 100
ELSE_IF | {결과} | EQ | 재시도
  CLICK | 150 | 150
ELSE
  CLICK | 200 | 200
END_IF

# WHILE 루프
SET | {i} |  | 0
WHILE | {i} | < | 5
  CLICK | 100 | {i}
  INC | {i}
END_WHILE

# REPEAT (5회) + 루프 카운터
REPEAT | 5
  NOTIFY | 1 |  | 반복 {$LOOP}회차
END_REPEAT

# SELECT / CASE
SELECT | {모드}
  CASE | A
    CLICK | 100 | 100
  CASE | ELSE
    CLICK | 300 | 300
END_SELECT

# 서브루틴
CALL |  |  | 인사하기
EXIT
LABEL |  |  | 인사하기
  TYPE | 0 |  | 안녕하세요
RETURN

# FOREACH_ROW
FOREACH_ROW | 고객목록.xlsx | Sheet1!A1:C100 | VISIBLE_ROWS
  NOTIFY | 1 |  | {$RIDX}: {$ROW.이름}
END_FOREACH
```

## B. 동작 (ACTION) — 6개

마우스·키보드 입력. 좌표는 **화면 픽셀**(0,0 = 좌상단)입니다.

| 명령어 | P1 (C) | P2 (D) | P3 (E) | 설명 |
|--------|--------|--------|--------|------|
| `MOVE` | x (num, 필수) | y (num, 필수) | 사후대기ms (num, 옵션) | 커서를 (x, y)로 이동 |
| `CLICK` | x (num, 필수) | y (num, 필수) | 사후대기ms (num, 옵션) | (x, y) 좌클릭 |
| `RCLICK` | x (num, 필수) | y (num, 필수) | 사후대기ms (num, 옵션) | (x, y) 우클릭 |
| `KEY` | 키코드/이름 (str, 필수) | — | 사후대기ms (num, 옵션) | 단일 키 입력 |
| `COMBO` | key1 (str, 필수) | key2 (str, 필수) | 사후대기ms (num, 옵션) | 조합 키 (예: Ctrl+C) |
| `TYPE` | 딜레이ms (num, 옵션) | — | 텍스트 (str, 필수) | 텍스트를 문자당 딜레이로 입력 |

- **사후대기ms**는 동작 후 추가 대기 시간(밀리초)입니다. 음수이거나 Long 범위를 넘으면 입력 전에 중단합니다. 대기 중 `Esc`로 중단할 수 있습니다.
- `CLICK`, `RCLICK`, `CLICK_SYNC`는 버튼을 누르기 직전에 포인터 위치를 확인합니다. 지정 좌표와 다르거나 위치를 읽지 못하면 클릭 전에 중단합니다.
- `TYPE`의 딜레이가 0 이하이면 안정성을 위해 **문자당 50ms**가 적용됩니다. 텍스트는 **P3(E열)**에 입력합니다.

중단 요청 후에는 새 클릭이나 키 누름을 실행하지 않습니다. 이미 누른 키와 버튼은 해제를 시도하고, 입력 API가 실패하면 명령 실패로 종료합니다.

### 키 이름 (KEY / COMBO)

숫자 VK 코드는 1~254의 정수를 십진 숫자로 적습니다. 예를 들어 `46`은 Delete입니다. 문자열 `45.6`, `1E2`, `&H2E`는 키 입력 전에 거부합니다. 아래 키 이름도 사용할 수 있습니다.

영문자 한 글자도 허용하며 대소문자를 구분하지 않습니다. 문장부호는 키 이름으로 허용하지 않으므로 문자 입력에는 `TYPE`을 사용합니다.

```
ENTER/RETURN(13)  ESC/ESCAPE(27)  TAB(9)   CTRL/CONTROL(17)  ALT/MENU(18)
SHIFT(16)  WIN/WINDOWS(91)  SPACE/SPC(32)  BS/BACKSPACE(8)   DEL/DELETE(46)
INS/INSERT(45)  HOME(36)  END(35)  PGUP/PAGEUP(33)  PGDN/PAGEDOWN(34)
UP(38)  DOWN(40)  LEFT(37)  RIGHT(39)  PRTSC(44)  CAPS(20)  F1~F12
```

### 예제

```
MOVE  | 100 | 200 | 500       # (100,200)로 이동 후 0.5초 대기
CLICK | 150 | 250             # 좌클릭
RCLICK| 160 | 260             # 우클릭
KEY   | ENTER                 # 엔터
KEY   | F5    |   | 300       # F5 누르고 0.3초 대기
COMBO | CTRL  | C             # Ctrl+C (복사)
TYPE  | 50    |   | 안녕하세요  # 50ms 간격으로 입력
```

## C. 메모리 (MEMORY) — 3개

사용자 변수에 값을 저장·증감합니다.

| 명령어 | P1 (C) | P2 (D) | P3 (E) | 설명 |
|--------|--------|--------|--------|------|
| `SET` | 좌변/주소 (str, **RAW**, 필수) | — | 값 (str, 필수) | 변수에 값 대입 |
| `INC` | 좌변/주소 (str, **RAW**, 필수) | — | 증분 (num, 옵션, 기본 1) | 숫자 변수 증가 |
| `DEC` | 좌변/주소 (str, **RAW**, 필수) | — | 감분 (num, 옵션, 기본 1) | 숫자 변수 감소 |

- **좌변(P1)은 RAW**이며 반드시 `{ }`로 감싸야 합니다. 허용 대상:
  - `{변수명}` — 사용자 변수 (대소문자 무시)
  - 변수명 내부에는 `{` 또는 `}`를 넣을 수 없습니다. `{a}{b}`처럼 여러 토큰을 이어 붙인 쓰기 주소도 거부합니다.
  - `{$CLIP}` — 클립보드 (쓰기 대상으로 허용)
  - 읽기 전용 시스템 토큰(`{$LOOP}` `{$PIXEL}` `{$BLANK}` 등)은 좌변으로 쓸 수 없습니다(오류).
- `SET | {변수명} | | {$BLANK}`처럼 빈 문자열을 저장해도 변수는 **정의된 상태**입니다.
- `INC`/`DEC`는 미정의 변수를 0으로 간주하지 않습니다. 카운터는 먼저 `SET | {카운터} | | 0`으로 초기화해야 합니다.
- `INC`/`DEC`의 현재 숫자가 정수 범위(-2147483648~2147483647)를 넘으면 원래 값을 보존하고 오류로 중단합니다. 숫자가 아닌 현재값을 0으로 보는 기존 동작은 유지합니다.

### 예제

```
SET | {카운터} |  | 0          # 카운터 = 0
SET | {이름}   |  | 홍길동      # 이름 = 홍길동
SET | {복사본} |  | {$CLIP}     # 클립보드 내용을 변수로
SET | {$CLIP}  |  | {이름}      # 변수 값을 클립보드로
INC | {카운터}               # +1 (기본)
INC | {카운터} |  | 5          # +5
DEC | {카운터} |  | 2          # -2
```

## D. 시스템 (SYSTEM) — 4개

창 제어, 대기, 알림, 종료.

| 명령어 | P1 (C) | P2 (D) | P3 (E) | 설명 |
|--------|--------|--------|--------|------|
| `FOCUS` | — | — | 창제목 (str, 필수) | 제목으로 창을 전면화. 미발견 또는 활성화 실패 시 오류, 성공 시 0.5초 대기 |
| `SLEEP` | — | — | 대기ms (num, 필수) | 지정 시간 대기 (`Esc`로 중단 가능) |
| `NOTIFY` | 표시초 (num, 선택) | — | 메시지 (str, 필수) | 토스트 알림 표시 |
| `EXIT` | — | — | — | 스크립트를 정상 종료 |

- `FOCUS`·`SLEEP`의 인자는 **P3(E열)**에 입력합니다.
- `FOCUS`의 창 제목은 토큰 치환 후에도 비어 있으면 안 됩니다. 빈 문자열이나 공백만 남으면 오류로 중단합니다.
- `SLEEP`은 음수 대기시간을 거부합니다. 75ms처럼 50ms의 배수가 아닌 값도 잔여 시간을 포함해 대기합니다. OS 스케줄링에 따라 실제 경과시간은 달라질 수 있습니다.
- `NOTIFY` 형식: P1에 표시 시간(초), P3에 메시지를 입력합니다. P1을 비우면 **기본 2초**, `0`이면 사용자가 확인할 때까지 대기합니다.
- `NOTIFY`의 P3에 있는 `|` 문자는 특별한 문법이 아니라 메시지 그대로 표시됩니다.
- `NOTIFY`의 표시 시간은 작성 직관성을 위해 초 단위이며, `SLEEP`과 동작 후 대기 값은 기존처럼 ms 단위입니다.

### 예제

```
FOCUS  |  |  | 메모장          # "메모장" 창을 앞으로
SLEEP  |  |  | 1000           # 1초 대기
NOTIFY | 3 |  | 작업 완료      # 3초간 알림
NOTIFY |   |  | 저장됨          # 2초(기본) 알림
NOTIFY | 0 |  | 확인 필요      # 확인할 때까지 대기
EXIT                          # 종료
```

## E. 비전 (VISION) — 4개

픽셀 색상을 기준으로 화면과 동기화하거나 결과를 검증합니다. 색상은 Windows 색상값과 같은 16진수 `BBGGRR` 형식입니다. 빨강은 `0000FF`, 파랑은 `FF0000`입니다. 기존 HUD 캡처값은 그대로 사용합니다. 화면 밖 좌표 등 픽셀을 읽지 못하는 경우에는 오류로 중단합니다.

| 명령어 | P1 (C) | P2 (D) | P3 (E) | 설명 |
|--------|--------|--------|--------|------|
| `WAIT_APPEAR` | x (num, 필수) | y (num, 필수) | hexColor (str, 필수) | (x,y) 픽셀이 지정 색이 될 때까지 대기 |
| `WAIT_VANISH` | x (num, 필수) | y (num, 필수) | hexColor (str, 필수) | (x,y) 픽셀이 지정 색에서 벗어날 때까지 대기 |
| `CLICK_SYNC` | x (num, 필수) | y (num, 필수) | — | (x,y) 좌클릭 후 색 변화(반응)를 확인하고 진행 |
| `ASSERT` | x (num, 필수) | y (num, 필수) | 조건 (str, 필수) | (x,y) 픽셀 색을 검증 |

- `WAIT_APPEAR`·`WAIT_VANISH`·`CLICK_SYNC`는 **타임아웃 30초**입니다. 시간 내 조건 미충족 시 오류로 중단됩니다 (`Esc`로도 중단 가능).
- Pause로 일시정지한 시간은 위 30초 제한에 포함하지 않습니다. 재개하면 남은 시간 동안 기다리며, 정지 중에도 `Esc`로 중단할 수 있습니다.
- `WAIT_APPEAR`와 `WAIT_VANISH`는 색상의 대소문자와 양끝 공백을 무시하며, 16진수 여섯 자리만 허용합니다. 잘못된 색상이나 토큰 치환 후 빈 색상은 오류로 중단합니다.
- `ASSERT`의 조건(P3)은 `!BBGGRR` 형식으로 **"이 색이 아니어야 함"**을 검사합니다. 실패 시 오류.
- `ASSERT`는 색상의 대소문자와 조건 양끝 공백을 무시합니다. 선택적인 `!` 뒤에는 16진수 여섯 자리만 허용하며, 잘못된 색상은 오류로 중단합니다.

### 예제

```
WAIT_APPEAR | 100 | 200 | 0000FF    # (100,200)이 빨강이 될 때까지 대기
WAIT_VANISH | 150 | 250 | 00FF00    # (150,250)이 초록에서 바뀔 때까지 대기
CLICK_SYNC  | 200 | 300             # 클릭하고 반응 확인
ASSERT      | 50  | 50  | !FFFFFF   # (50,50)이 흰색이면 실패
```

## 조건 연산자 (IF / ELSE_IF / WHILE 의 P2)

`IF`/`ELSE_IF`/`WHILE`의 연산자(P2)는 **RAW**로 처리되며, 아래 목록만 허용됩니다 (`IsConditionOperator` 기준).

| 연산자 | 의미 |
|--------|------|
| `EQ` / `==` | 정확히 같음 (`*` `?`는 와일드카드가 아닌 리터럴로 취급) |
| `!=` | 다름 |
| `>` `<` `>=` `<=` | 수치 비교 |
| `LIKE` | 와일드카드 패턴 — `*`(임의 길이) `?`(한 글자) `#`(한 숫자) |
| `STARTS` | 좌변이 우변으로 시작 |
| `ENDS` | 좌변이 우변으로 끝 |
| `CONTAINS` | 좌변이 우변을 포함 |

숫자로 해석되는 두 피연산자는 자릿수를 보존해 비교합니다. 예를 들어 텍스트로 저장한 9007199254740992와 9007199254740993은 `EQ`와 `CASE`에서 구분됩니다. Excel이 셀 입력 시 이미 반올림한 식별번호의 원본 자릿수는 셀을 텍스트 형식으로 지정한 뒤 입력해야 보존됩니다.

> ⚠️ `NE`, `LT`, `LE`, `GT`, `GE`, `IN`, `NOTCONTAIN` 등은 **존재하지 않는 연산자**입니다. 사용하면 검증 오류로 표시됩니다.

```
IF | {횟수}   | >        | 10
IF | {파일명} | ENDS     | .xlsx
IF | {상태}   | CONTAINS | 완료
IF | {코드}   | LIKE     | A##         # A 뒤 숫자 2자리
```

## 토큰·변수 시스템

RESOLVE 슬롯의 파라미터는 실행 시 `{ }` 토큰이 실제 값으로 치환됩니다.

### 고정 토큰 (정적 문자)

| 토큰 | 값 |
|------|-----|
| `{$BLANK}` | 빈 문자열 |
| `{$TAB}` | 탭 문자 |
| `{$CR}` | 캐리지 리턴 |
| `{$LF}` | 라인 피드 |
| `{$SPACE}` | 공백 한 칸 |

### 동적 토큰 (런타임 값)

| 토큰 | 값 |
|------|-----|
| `{$CLIP}` | 현재 클립보드 텍스트 |
| `{$LOOP}` | 최내곽 루프의 현재 반복(1부터), 루프 밖이면 빈값 |
| `{$RIDX}` | 최내곽 `FOREACH_ROW`의 현재 행 순번(1부터), 순회 밖이면 빈값 |
| `{$RTOTAL}` | 최내곽 `FOREACH_ROW`의 전체 순회 행수, 순회 밖이면 원문 유지 |
| `{$ROW.헤더명}` | 현재 `FOREACH_ROW` 행의 헤더별 값, 순회 밖이면 원문 유지 |
| `{$PIXEL:x,y}` | (x,y) 픽셀 색상 `BBGGRR` |

`{$PIXEL:x,y}`는 숫자 좌표 두 개가 필요합니다. 좌표 누락, 잘못된 숫자, Long 범위 초과는 오류로 중단하며 0으로 대체하지 않습니다.

### 사용자 변수

`{$CLIP}`은 클립보드에 텍스트가 없으면 빈 문자열을 반환합니다. 다른 프로그램이 클립보드를 사용 중이거나 텍스트 읽기에 실패하면 오류로 중단합니다.

`{변수명}` — `SET`/`INC`/`DEC`로 만든 변수. 대소문자를 구분하지 않습니다.

- 사용 전에 반드시 정의되어 있어야 하며, 미정의 변수는 실행 오류로 중단됩니다.
- 빈 문자열은 `{$BLANK}`로 의도적으로 저장할 수 있고, 이 경우에도 정의된 변수로 취급됩니다.
- `$` 접두 시스템 토큰(`{$BLANK}` `{$CLIP}` `{$LOOP}` `{$RIDX}` `{$RTOTAL}` `{$ROW.*}` `{$PIXEL:*}` 등)은 사용자 변수 검사 대상이 아닙니다.

### 중첩 해석

토큰 안에 토큰을 넣을 수 있습니다(재귀 치환):

```
SET | {x} |  | 100
SET | {y} |  | 200
IF  | {$PIXEL:{x},{y}} | EQ | FFFFFF      # (100,200) 색이 흰색이면
  NOTIFY |  |  | 흰색 감지
END_IF
```
