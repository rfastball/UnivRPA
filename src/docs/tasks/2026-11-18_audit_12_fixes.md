# 감사 결과 12건 수정 계획

대상은 현재 작업 트리와 UnivRPA.xlsm이다. 시작 시점의 공개 테스트는 21개이며 직전 감사에서 모두 통과했다.

1. 입력과 진단 데이터 보호 (1, 2, 5, 8). 클릭 직전 실제 포인터 검증, 진단 시트 소유권, 동작 전 대기시간 및 미사용 슬롯 검사.
2. 실행 의미 보정 (4, 7, 9, 10). 음수 반복 차단, 긴 숫자 비교, 전체 시트 범위 축소, 표 스냅샷 중 중단 처리.
3. 편집기와 HUD (3, 6, 11, 12). 수식 보존, Caps Lock 초기 상태 반영, 이동 실패 안내, 중복 검사 제거.
4. 동작 계약을 매뉴얼에 반영하고 lint, push/컴파일, 소유 테스트, 전체 테스트, diff, lease 해제를 수행한다.

## Test delta brief

- Unique risk: 포인터가 이동과 클릭 사이에 바뀌는 경우, 잘못된 대기/슬롯으로 실제 입력이 발생하는 경우, 큰 정수의 서로 다른 값이 같아지는 경우, 음수 반복, 수식 소실, 잘못된 표 범위/중단 및 편집 중 이동 실패. 기존 정상 경로와 API 자체 실패 검증으로는 구분되지 않는다.
- Existing owner: modTester의 TC_AbortLatch, TC_FlowNegativePaths, TC_ParseStrict, TC_ForeachRowExecution, TC_ScriptAssistFormatterRegression. 진단 시트는 기존 각 스위트의 생성/정리 경로에서 확인한다.
- Selected layer: 입력은 기존 가상 드라이버, 비교와 분기는 배열, 서식과 범위는 기존 임시 워크시트로 검증한다.
- Expected cost delta: 공개 테스트, 테스트 파일, 스위트당 Excel 시작 및 외부 프로세스 추가 0. 실제 키 입력이나 장시간 대기를 추가하지 않는다.
- Evidence to retire: 기존 미사용 슬롯의 숫자 0 자리채움은 빈 슬롯으로 바꾸고, 명시적인 잘못된 값은 별도 회귀 사례로 검증한다.
